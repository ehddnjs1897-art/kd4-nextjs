## PART A. 사용자 원문 계획 (1~18절)

### 1. 여행 기간
- 출국: 2026년 9월 24일
- 귀국: 처음에는 9월 29~30일 예정이었으나 현재는 **10월 3~4일까지 체류 가능성 있음**
- 목적: 장막절 기간 이스라엘 체류 / 예루살렘 성지순례 / 갈릴리·Jesus Trail 걷기 / 현지 친구 방문 / 교회 방문 / 노숙자 사역 참여 / 샤밧과 절기를 현지에서 직접 경험

### 2. 현지에서 이용 가능한 숙소
**A. 예후드(Yehud) 친구 집** — 벤구리온공항에서 가까움. 입국 첫날 숙박 후보 1순위. 필요하면 다른 날에도 숙박 가능. 역할: 입국 베이스.
**B. Ramat Gan 숙소** — HaRoe 91, Ramat Gan. 텔아비브 바로 동쪽, Bnei Brak 인접. 텔아비브 일정 때 사용, 특히 귀국 전 마지막 숙소로 활용 가치 높음. 역할: 텔아비브 + 출국 베이스.
**C. 사해 친구 집** — Dead Sea 지역, 숙박 가능. 정확한 마을/주소 미정. 사해 방문·유대광야 일정·필요시 1박. 역할: 사해/광야 베이스.

### 3. 반드시 또는 가급적 방문할 곳 — 예루살렘 (중요도 매우 높음)
Old City / Jaffa Gate / Ramparts Walk(성벽 위 걷기) / Lions' Gate / Via Dolorosa / Ecce Homo / Bethesda Pool / St. Anne Church / Church of the Holy Sepulchre / Western Wall / Mount of Olives / Gethsemane / 가능하면 City of David·Mount Zion

**성벽투어**: Ramparts Walk 중 특히 북부 코스 선호 — Jaffa Gate → New Gate → Damascus Gate → Herod's Gate → Lions' Gate.
성벽에서 내려온 후 동선: Lions' Gate → Bethesda / St. Anne → Ecce Homo → Via Dolorosa → Holy Sepulchre.

### 4. 교회 관련
**Pniel Church** — 갈릴리/Tiberias 지역. 방문 희망. 가능하면 현지 교회 공동체 경험. 샤밧 예배 참석 여부는 미결정. 토요일 예배 참석이 필수라면 전체 갈릴리 일정 조정 필요.
**"에케호마 교회"** — 사용자가 기억을 요청. 현재 Ecce Homo와 연결해 다루고 있으나 정확히 Ecce Homo Convent인지 최종 확인 필요. 예루살렘 일정에 반드시 반영.

### 5. Jesus Trail
전체 코스(약 65km): Nazareth → Zippori → Cana → Lavi → Horns of Hattin → Arbel → Magdala → Tabgha → Mount of Beatitudes → Capernaum.
원래 질문은 가버나움→나사렛 방향으로 걸을 수 있는지였고, 이후 Jesus Trail 기준으로 일정을 다시 짜기로 함.

**시간이 부족할 경우 최우선 핵심 구간 (약 18~20km)**:
Arbel → Wadi Hamam → Magdala/Migdal → Sea of Galilee → Tabgha → Mount of Beatitudes → Capernaum
이유: 갈릴리 산악 풍경·막달라·갈릴리 호수·오병이어 지역·팔복산·가버나움을 하루에 연결 가능.
여행이 10/3~4까지 늘어나면 하루 이상 확대 가능.

### 6. Tel Aviv 사역 — Beit Tamchui
주소: HaGalil 5, Tel Aviv. 무료급식/노숙자·빈곤층 지원 사역.
**확정 일정: 2026년 10월 1일 목요일** — 오후 5:00 샌드위치 만들기 → 약 6:30 거리 아웃리치 출발.
→ 10/1 오후~저녁 다른 일정 금지. 숙박은 Ramat Gan HaRoe 91.

### 7. 장막절 관련
핵심 목적. 관심 행사: 장막절 개막 분위기 / 예루살렘 행사 / Jerusalem March / 광야 체험 / 현지 샤밧·절기 경험.
이전 검토한 ICEJ 일정: Kfar HaNokdim Desert Experience, Jerusalem March, Garden Tomb Communion. 단 ICEJ 행사 참석을 전부 확정한 것은 아님.

### 8. 샤밧 / 절기 이동 원칙 (매우 중요)
렌터카 없이 여행하는 안을 우선 검토. 샤밧·절기로 버스·기차가 안 다니는 날에는 장거리 이동 금지, 대부분 걸어서 다닐 수 있는 지역에 머문다.
- 샤밧에 좋은 곳: **예루살렘 Old City** (감람산·겟세마네·Lions' Gate·Via Dolorosa·Ecce Homo·Holy Sepulchre·Western Wall 도보). Tel Aviv(주말 일부 교통·택시 가능하지만 한 지역에 머무는 방식).
- 샤밧에 피할 것: 예루살렘↔갈릴리, 예루살렘↔사해, Tiberias↔Tel Aviv 장거리 이동, Jesus Trail 출발점으로 대중교통 이동.
- 즉 금요일 오후 전에 해당 지역에 들어가서 토요일 동안 걸어서 여행.

### 9. 렌터카에 대한 현재 판단
전 일정 렌터카 불필요. 차 불필요 지역: Tel Aviv·Ramat Gan·Jerusalem Old City. 차 있으면 매우 편한 지역: Dead Sea·Galilee·Arbel·Capernaum·Jesus Trail 접근.
→ 필요하면 갈릴리/사해 구간만 2~3일 단기 렌트 고려. 기본은 대중교통 + 도보 + 필요시 택시.

### 10. 현재까지 가장 자연스러운 여행 구조
- 9/24 목: 한국 → Ben Gurion → Yehud 친구 집. 무리한 관광 X.
- 9/25 금 이후: 예루살렘 또는 사해 쪽으로 이동. 샤밧 시작 전에 숙박 지역으로 완전히 들어가야 함.
- 첫 번째 샤밧: 가급적 Jerusalem Old City 중심 도보 순례 (Mount of Olives → Gethsemane → Lions' Gate → Bethesda → St. Anne → Via Dolorosa → Ecce Homo → Holy Sepulchre → Western Wall).
- 사해: 별도 하루 또는 1박. 사해 친구 집 활용. Dead Sea / Ein Gedi 또는 인근 / 유대광야 중 선택. 억지로 하루에 다 넣지 않음.

### 11. 예루살렘 집중 하루
샤밧과 별도로 평일 하루: Ramparts Walk 09:00 전후 Jaffa Gate 시작 → New Gate → Damascus Gate → Herod's Gate → Lions' Gate → Ecce Homo → Via Dolorosa → Old City. Jerusalem March 날짜가 맞으면 참가 고려.

### 12. 갈릴리
베이스는 Tiberias가 가장 현실적. 희망: Pniel Church / Nazareth / Cana / Arbel / Magdala / Tabgha / Mount of Beatitudes / Capernaum / Jesus Trail. 시간 배분이 핵심.

### 13. 숙박 배치 원칙
Yehud = 입국 첫날 / Jerusalem = 장막절·Old City·샤밧 / Dead Sea 친구집 = 사해·광야 / Tiberias = Galilee·Jesus Trail / Ramat Gan = Tel Aviv 사역 + 출국 전

### 14. 10월 1일은 반드시 Tel Aviv

### 15. 10월 2~3일 샤밧 대응
10/3까지 체류 시 10/2(금) 오후 이전에 샤밧 지역 이동 완료.
- 안 1 — Jerusalem (가장 추천): 10/2 오후 도착 → 금요일 저녁 → 10/3 Old City 도보.
- 안 2 — Tel Aviv: Ramat Gan/Tel Aviv 도보 + 택시/주말교통.
